# Czcionki do ofert PDF

Niezmienione pliki Liberation Sans Regular i Bold oraz `LICENSE_LIBERATION`
pochodzą z dystrybucji `pdfjs-dist/standard_fonts`. Obie odmiany obsługują
polskie znaki i są udostępnione na licencji SIL Open Font License 1.1.

Pliki są serwowane z tej samej domeny co konfigurator i pobierane dopiero
podczas generowania PDF. Nie zwiększają początkowego pobierania sceny 3D.
